# KROPP Fitness Club Landing Page

Учебный проект лендинга фитнес-клуба. Это мой третий проект, на котором я углубляю навыки работы с БЭМ, SCSS и осваиваю CSS Grid, псевдоэлементы и более сложные приёмы вёрстки.

## Цель проекта
Усложнить и разнообразить вёрстку: освоить CSS Grid, работать с `::before`/`::after` для декоративных элементов, использовать продвинутые функции SCSS.

## Технологии
* **HTML5**: семантическая разметка, формы с `<label>`, `<table>` с `<caption>`, `<time>`, скрытые заголовки для доступности.
* **CSS3**: Flexbox и CSS Grid, `::before`/`::after` с `content: attr()`, `-webkit-text-stroke`, `min()`, `vw`-единицы, фоновые изображения.
* **SCSS**: переменные, вложенность, модификаторы BEM.
* **Normalize.css**: сброс стилей браузера.
* **Flaticon**: иконки соцсетей и UI-элементы (CDN).

## Чему я научился
* Комбинировать Flexbox и CSS Grid для построения макета.
* Использовать `::before`/`::after` для создания декоративных подложек и иконок.
* Применять `content: attr(data-title)` для вывода текста из HTML-атрибутов.
* Работать с `min()` и `vw` для адаптивной типографики без медиазапросов.
* Стилизовать формы, таблицы и текстовые поля.
* Использовать SVG-иконки в составе кнопок.

## Текущее состояние
* **Адаптивность**: страница оптимизирована только под десктопные экраны.
* **Код**: проект усложняется с каждым шагом — здесь уже больше секций, форм и декоративных элементов, чем в предыдущих работах.
